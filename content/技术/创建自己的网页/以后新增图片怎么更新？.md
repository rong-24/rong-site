
以后你只需要：

1. 把新图片放进：

```
/Users/liu/Pictures/personal_gallery_raw
```

2. 重新运行：

```
cd ~/Web/rong-sitesource .venv/bin/activatepython scripts/build_gallery.py \  --src "/Users/liu/Pictures/personal_gallery_raw" \  --vault "$PWD/content" \  --title "我的图片库" \  --page-size 120
```

3. 本地预览：

```
npx quartz build --serve
```

4. 发布：

```
git add content/图片库.md content/图库分卷 content/assets/gallerygit commit -m "update image gallery"npx quartz sync
```

如果你改了压缩参数，想全部重新生成图片，用：

```
python scripts/build_gallery.py \  --src "/Users/liu/Pictures/personal_gallery_raw" \  --vault "$PWD/content" \  --title "我的图片库" \  --page-size 120 \  --force
```
