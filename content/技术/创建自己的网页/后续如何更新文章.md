## 1. 打开 Obsidian

打开这个库：

```
~/Web/rong-site/content
```

## 2. 新建文章

比如：

```
日常/2026-05-07-今天的记录.md
```

文章开头建议统一加：

```
---
title: 今天的记录
date: 2026-05-07
tags:
  - 日常
draft: false
---
```
## 3. 本地预览

```
cd ~/Web/rong-site npx quartz build --serve
```

## 4. 发布

```
cd ~/Web/rong-site npx quartz sync
```

然后等一会儿，Cloudflare Pages 会自动更新网站。
