### 第一步：抓取知乎收藏

```
cd /Users/liu/zhihu_fav_export
python3 capture_zhihu_collection.py
```

---
### 第二步：增量分类

```
python3 classify_zhihu_contents.py
```

---
### 第三步：增量导出到 Quartz

```
python3 export_zhihu_to_quartz.py \  --src "/Users/liu/zhihu_fav_export/zhihu_collection_724494165/classified_contents" \  --dst "$HOME/Web/rong-site/content/知乎收藏"
```

---

### 第四步：预览和同步

```
cd "$HOME/Web/rong-site"
npx quartz build --serve
浏览器打开：http://localhost:8080/知乎收藏/
```

确认没问题后：

```
npx quartz sync
```

所有原知乎收藏内容都在`/Users/liu/zhihu_fav_export/zhihu_collection_724494165/contents`目录下
